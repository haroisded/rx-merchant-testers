# 자주 묻는 질문

## 에이전트 20개가 같은 버그를 20번 찾기만 하나요?

아니요. LocalSend에서 보고서 103개는 서로 다른 버그 46개였고, 그중 29개는 차단 버그를 포함해 에이전트 하나만 발견했습니다([차트](examples.md#localsend-에이전트-20개-기기-20대-14개-언어)). 오른쪽에서 왼쪽으로 쓰는 언어의 버그는 아랍어 페르소나 두 개에서만, 태블릿 버그는 태블릿 네 대에서만 나왔습니다. 중복된 것은 빈 기기 목록처럼 누구나 겪는 앱 전체 상태였습니다.

## 비용은 얼마인가요?

GitHub 러너는 macOS를 포함해 공개 저장소에서 무료입니다. [이 실행들](../../../docs/runs/)에서 모델 사용량은 에이전트당 $0.15~$0.55였으므로 휴대폰 20대에 약 $5입니다. Claude 구독을 사용하면 실행은 청구서 대신 플랜 사용량에 포함됩니다. 비용을 줄이려면 `model=haiku` 또는 다른 제공업체의 모델을 사용하세요: [docs/cheaper-models.md](../../../docs/cheaper-models.md).

## 실행에는 얼마나 걸리나요?

각 에이전트는 1~18분 동안 탐색합니다. AnkiDroid의 Android 에이전트 10개는 시작부터 마지막 보고서까지 10분 미만이 걸렸습니다. LocalSend의 기기 20대는 빌드를 포함해 69분이 걸렸는데, 무료 플랜이 macOS 작업을 한 번에 5개만 실행하기 때문입니다.

## Mac이 필요한가요?

아니요. 모든 것이 GitHub 러너에서 실행됩니다. Android는 Linux, iOS는 macOS입니다. `gh` CLI와 Claude 구독 또는 API 키만 있으면 되고, 나머지는 `./setup.sh`(Windows에서는 `.\setup.ps1`)가 처리합니다.

## 두 번 실행하면 같은 결과가 나오나요?

아니요. 각 에이전트가 탐색하므로 두 실행이 같은 경로를 가는 법은 없습니다. 같은 목록이 아니라 같은 종류의 버그를 기대하세요. 회귀 테스트에는 스크립트 기반 테스트(Maestro, Appium)를 계속 사용하세요. [비교 방법](../../../docs/compare.md)을 참고하세요.

## 내 보고서는 공개되나요?

아니요. 공개 저장소의 로그는 공개되므로 보고서, 스크린샷, 영상은 러너를 떠나기 전에 사용자의 키로 암호화되며 사용자만 복호화할 수 있습니다. 분석 호스트는 휴대폰 안에서 차단됩니다. 실제 계정이 아닌 테스트 계정을 사용하세요. 자세한 내용은 [PRIVACY.md](../../../PRIVACY.md)를 참고하세요.

## 비공개 소스 앱도 테스트할 수 있나요?

예. 비공개 저장소에서 워크플로를 실행하고 앱 저장소에는 읽기 전용 `SOURCE_REPO_TOKEN`을 사용하거나, `android_build`와 `ios_build`가 미리 빌드된 APK 또는 .app을 가리키게 하세요. 비공개 저장소는 Actions 사용 시간(분)을 소모하며, macOS 분은 10배로 계산됩니다.

## 나만의 페르소나를 만들 수 있나요?

예. 페르소나는 [personas.json](../../../personas.json)의 몇 줄입니다. 기기, OS 버전, 언어, 글자 크기, 다크 모드, 위치, 어떤 사람인지, 무엇을 시도할지 정합니다. `device`의 선택 설정: `"increase_contrast": true`(iOS의 Increase Contrast, Android의 고대비 텍스트), `"reduce_motion": true`(iOS와 웹: Android 에뮬레이터는 이미 애니메이션을 끄고 실행), `"color_filter"`(`"protanopia"`, `"deuteranopia"`, `"tritanopia"`, Android, iOS, 웹 스크린샷에 적용), `"network"`(`"slow"` 또는 `"flaky"`, Android 에뮬레이터 전용).

## 무엇을 잘못 판단하나요?

때때로 화면을 잘못 읽습니다. LocalSend의 에이전트 20개 중 3개가 시뮬레이터의 영어 키보드를 앱의 일부로 표시했습니다. 에이전트당 몇 분은 주요 경로를 다루지만 큰 앱의 모든 구석을 다루지는 않습니다. 모든 발견에는 번호가 매겨진 스크린샷이 있으니, 이슈를 올리기 전에 확인하세요.

## 제한 사항

- GitHub 러너는 공개 저장소에서 무료입니다. 동시에 약 20개 작업, macOS에서는 5개입니다.
- 5시간 사용 한도가 있는 플랜에서는 에이전트 20개가 약 15분 만에 한도를 다 쓸 수 있습니다. 6~10개씩 배치로 실행하세요.
- 호스팅 러너는 저장소 자체 프로젝트를 위한 것입니다. 비공개 소스 앱이라면 비공개 저장소나 자신의 Mac에서 워크플로를 실행하세요.

## 작동 방식

<p align="center"><img src="../../../assets/how-it-works.svg" alt="작동 방식: 워크플로 하나가 앱을 빌드한 다음, 페르소나마다 에이전트 하나와 에뮬레이터 또는 시뮬레이터 하나, 암호화된 보고서, 사용자의 컴퓨터에서 생성되는 요약" width="100%"></p>

- **페르소나**가 기기를 설정합니다: 모델, OS, 글꼴 크기, 다크 모드, 언어, 위치.
- **에이전트당 세 가지 도구**: 화면 보기(탭 좌표 포함), 제스처, 입력.
- **모든 화면의 접근성 검사**: 이름 없는 컨트롤과 48 dp(Android) 또는 44 pt(iOS) 미만의 터치 대상으로, 에이전트가 스크린샷에서 확인합니다.
- **암호화된 결과**: 공개 저장소 로그는 공개되므로 모든 것이 사용자의 키로 암호화됩니다.
- **분석 차단**: 휴대폰 안에서 차단되므로 테스트가 실제 통계에 영향을 주지 않습니다.
- **하나의 요약**이 사용자의 컴퓨터에 생성됩니다. `SUMMARY_GROUPING=1`이면 Claude가 같은 버그를 설명하는 보고서를 묶고(Claude 로그인으로 한 번 호출), 각 버그를 몇 개의 페르소나가 발견했는지, 어떤 페르소나가 어떤 종류의 문제를 찾았는지 볼 수 있습니다. `SUMMARY_WEBHOOK_URL`을 설정하면 짧은 버전이 사용자의 컴퓨터에서만 Slack 또는 Discord 웹훅으로도 전송됩니다.
- **이슈 초안**이 사용자의 컴퓨터에 생성됩니다. `python3 scripts/draft_issues.py runs/<id>`는 `SUMMARY.md`의 각 발견 사항에 대해 GitHub 이슈 하나를 미리 보여 주고, `--create --repo OWNER/REPO`를 붙이면 `gh`로 확인한 이슈를 엽니다.
- **테스트**는 푸시할 때마다 오프라인으로, 휴대폰 없이 실행됩니다: 접근성 검사, 페르소나 매트릭스, 요약, 암호화된 결과([tests/](../../../tests/)).

## Maestro, Appium, agent-device를 쓰지 않는 이유는?

그들은 여러분이 작성한 테스트를 실행합니다. 이 에이전트들은 아무도 테스트할 생각을 하지 못한 것을 찾습니다.

| | mobile-agent-testers | Maestro, Appium, Detox, e2e |
|---|---|---|
| 작성할 것 | 없음: 목록에서 페르소나 선택 | 흐름 또는 테스트 코드 |
| 잡아내는 것 | 끊긴 흐름, 조용한 오류, 누락된 번역, 큰 글자에서의 레이아웃, 다크 모드, 혼란스러운 문구 | 각 테스트가 확인하는 것 |
| 실행마다 같은 결과 | 아니요: 매번 탐색하므로 스크린샷 확인 필요 | 예 |

[agent-device](https://github.com/callstackincubator/agent-device)는 코딩 에이전트 하나에게 시뮬레이터 하나를 맡깁니다. 이 프로젝트는 전체 세션을 실행합니다. 앱을 빌드하고, 각 페르소나에 자신의 기기를 주고, 암호화된 보고서를 수집합니다. 릴리스 전에는 에이전트를, 회귀 테스트에는 스크립트 기반 흐름을 사용하세요.

Firebase Test Lab Robo, mobile-mcp, phonedriver, 사람 베타 테스터까지 포함한 전체 비교: [docs/compare.md](../../../docs/compare.md).
